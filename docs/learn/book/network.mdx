这本书其实要和《Wireshark 网络分析的艺术》一起看，因为都是同一个作者写的。而且两本书都很薄，差不多一周就看完了。

豆瓣上对这两本书的评价主要是集中在两方面：**优点**是风趣幽默深入浅出，结合部分案例讲解有种读侦探小说的感觉；**缺点**是对 Wireshark 的操作和网络协议的讲解并没有那么深入与体系化。

其实从我个人的角度看，这两本书真的写的非常棒，它其实适合有一定网络基础的人（起码学过一轮 HTTP 和 TCP/IP）并有基础的 Wireshark 操作经验，这时候再结合书中的案例，在作者诙谐的文笔下会对一些之前并不清楚的技术细节上有豁然开朗的感觉。

至于不是很体系化的缺点，我认为并不是这本书的问题。因为这本书本质上是作者的 **Blog 合集**，试图从 Blog 中获取体系化的知识肯定是不现实的。如果按这个角度去读书，就不会有相关困扰了。如果硬要我说缺点，那就是书籍的篇幅还是太短了，看的不过瘾 😂。
</Book>

很好的一本书，翻译也很顺畅，能看出来作者和译者的水平都很高。 

上篇介绍了 HTTP 的发展历史，整体的思路就是 互联网高速发展->现有协议遇到瓶颈->制定新协议解决瓶颈，这个思路非常的顺畅，读下来就能了解 HTTP 各个版本主要要解决的问题和对应的性能优化方案。

中篇介绍了 HTTP/2 的一些细节，例如优先级算法和压缩算法，还介绍了一些抓包思路和验证方案，在工程实践中也有借鉴价值，这块儿的内容个人认为难易度上处理的很好。因为书成文于 2019 年，在 2022 看，HTTP/2 push 因为使用率低，浏览器已经要放弃支持了，基本上可以认为是废案了，可以略去不看。 

后篇简单介绍了 QUIC 方案（可以简单理解为 HTTP/3），算是一个简单的扩展阅读，因为本书注重于 HTTP/2 的讲解，所以内容较少整体上也符合预期。

综合来看，是本非常好的书。
</Book>
