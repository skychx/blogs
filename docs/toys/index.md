## 一.画线

图形的渲染，都是从点线面开始的，点的绘制最简单了，只要有固定的坐标轴和一个确定的坐标点，就可以画一个点。

画线相对来说会麻烦一些，对于一张白纸来说，只要有两个点，铅笔直尺一划，就可以确定一条连续光滑的直线；对于屏幕来说，图像都是一个一个的坐标点，也就是说，直线本质上其实是由离散的点组成的，所以我们要用一个高效的算法来计算。
